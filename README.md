Currently supporting ArchiCAD 28 with the intent to maintain for perpetual licenses. 

**Tools**
**GH Calculator**: Floating Calculator that can be pinned
**GH Formula**: Floating scientific calculator
**GH Audio Manager**: Floating Windows Audio Stream Manager for inside ArchiCAD
**GH YouTube**: Watch YouTube inside ArchiCAD
**GH Mod Manager**: A floating favorites style pallet to store your Mods and
**GH XML Editor**: A floating pallet for Viewing and editing project info
**GH AI Render**: 3D window AI rendering tool for use with you preferred API (WIP, currently fixing a bug that causes ArchiCAD to crash after render)

**Objects**
Boundary Pro: A better boundary tool with setback options
Pool Pro: A generic pool builder
Mirror Pro: A customizable mirror object with shaving cabinet option
